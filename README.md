# AC1999 Client

Installer for the original 1999 Asheron's Call retail client used by AC1999.

## Installation

Download the latest **AC1999 Client Setup** from the [Releases](../../releases) section and run the installer.

The installer defaults to:

    C:\AC1999

You may select a different installation directory using the **Browse** button during installation.

The installer will create the selected directory if it does not already exist.

## Windowed Mode

The installer includes an optional:

**AC Windowed-acceelerated (dgVoodoo)**

configuration for players who want to run AC1999 in a window.

## AC1999 Launcher

The AC1999 Launcher is a separate application and is **not included** with this installer.

After installing the client, use the AC1999 Launcher to select the installed game directory and connect to an AC1999 server.

## The 1999 Client

AC1999 uses the original 1999 retail Asheron's Call game client.

This is not the later End of Retail client used by other Asheron's Call server projects.
